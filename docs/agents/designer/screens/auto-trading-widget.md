# 화면 명세 — 자동매매 위젯 (AutoTradingWidget)

> 최종 업데이트: 2026-08-24

## 레이아웃 와이어프레임 (텍스트 기반)

```
┌──────────────────────────────────────────────────────────┐
│ [MOCK/LIVE 배지]   전체매매 [ON/OFF 스위치]   [🛑 긴급정지]  │
├──────────────────────────────────────────────────────────┤
│ 포지션 현황                                                 │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐                │
│  │종목A       │ │종목B       │ │종목C       │  ...가로 스크롤 │
│  │+2.3%      │ │-1.1%      │ │+0.4%      │                │
│  └───────────┘ └───────────┘ └───────────┘                │
├──────────────────────────────────────────────────────────┤
│ AI 신호 피드                              주문 로그          │
│  10:32 종목A BUY 신뢰도 78%              10:33 종목A 매수 체결 │
│  10:15 종목D SELL 신뢰도 65%             10:16 종목D 매도 대기 │
├──────────────────────────────────────────────────────────┤
│ 리스크 상태  [게이지: 일일손실한도 대비 32%]                  │
├──────────────────────────────────────────────────────────┤
│ 성과 차트 (누적수익률 vs KOSPI)                              │
│  [라인 차트]                                                │
└──────────────────────────────────────────────────────────┘
```

## 상태별 분기

- **정상 운영**: 위 레이아웃 그대로 표시
- **키움 API 연결 끊김**: 헤더 바 하단에 경고 배너 삽입, 신규 신호/주문 섹션은 "일시 중단됨" 오버레이
- **긴급정지 발동됨(수동 또는 Kill Switch)**: 전체 위젯에 경고 테두리, 헤더 바에 "매매 중단됨" 상태 텍스트, `TradingToggleSwitch`는 비활성(OFF 고정) 상태로 표시되고 재개는 별도 승인 절차 안내 문구 노출
- **일일 손실 한도 도달(Circuit Breaker)**: 리스크 게이지 `--risk-critical`, "신규 주문 중단 — 일일 손실 한도 도달" 안내 문구
